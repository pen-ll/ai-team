# 测试领域平台适配映射表

> 本领域角色（`test-planner` / `runner`）收到 `platform` 参数后查此表。
> **[门禁] 本领域不持有平台特化 skill** —— 鸿蒙测试的环境事实与执行手段**直接引用开发领域的 `ai-team-dev-pt-hm-*`**，保持单一事实源、避免两套并行漂移。

## 映射规则

| platform | 环境事实（按需） | 执行驱动（按需） |
|----------|------------------|------------------|
| harmony | `ai-team-dev-pt-hm-env` | `ai-team-dev-pt-hm-ui-test` |

## 使用方式

1. 领域角色收到 PM 传来的 `platform` 参数
2. 读取本文件：`read_file("{skills_dir}/ai-team-qa/platform-map.md")`
3. 查表：在 `platform` 列匹配当前平台
4. 命中 → 按下方「按需加载」规则 `use_skill {对应列特化 skill}`
5. **「环境事实」列非空时不要立即加载** —— 仅在需要触碰环境时（CLI 能力自检 / 设备确认 / 安装启动 / 日志抓取）再 `use_skill`，避免无谓的上下文占用
6. **「执行驱动」列**：需要真机 UI 驱动与运行时取证时再 `use_skill`（同属按需，不提前加载）
7. **未命中平台** → 本领域**无执行侧能力**：`ask_followup_question` 告知用户「当前无对应执行侧 skill」并给选项 `["仍按鸿蒙流程试跑", "只出计划不执行", "取消本次测试"]`
   > **不得默认套用鸿蒙流程**，也不得假装支持其它平台。

## 已知缺口（[门禁] 按缺口登记，不得静默）

跨领域引用 dev 的 hm 体系意味着本领域**不持有**部分测试侧专属事实，执行时必须按缺口处置：

| # | 缺口 | 处置 |
|---|------|------|
| 1 | `ai-team-dev-pt-hm-ui-test` 的「报告落盘」章节写死 `coder-report.md` / `tester-report.md` | **由本领域角色覆盖**：`runner` 的产出路径固定为 `{artifact_dir}/test-report.md`，平台 skill 的落盘章节**不适用** |
| 2 | `ai-team-dev-pt-hm-ui-test` 的前置准备面向「刚构建完的产物」（新鲜度校验 + 安装） | 本领域**不编译**：被测物来源与新鲜度口径由 `ai-team-qa-role-runner` §二 界定；设备已装版本即「新鲜度未校验」，须在报告标注 |
| 3 | dev 的 hm 体系**不含应用定位命令**（`bm dump` 取 bundleName / mainElementName） | 应用定位改由**用户提供 bundleName**（见 `ai-team-qa-tool-testcase-plan` §3.3 固定必列项）；用户未给且确需探测 → 按 `ai-team-dev-pt-hm-env` E6 探索口径查证，**不得凭关键词猜应用** |
| 4 | dev 的 hm 体系**不含测试侧错误码判别表**（安装报错 / 启动失败） | 按 `ai-team-dev-pt-hm-env` E5 能力探测与失败项处置；无法判成因 → 原样记录报错并用选项问用户，**不猜成因** |
| 5 | dev 的 hm 体系**不含环境异常总表** | 环境 / 前置不满足且 AI 无法自行消除 → 按 `ai-team-qa-tool-workflow` **§2.3 环境异常处置总表**给选项问用户；**不得静默跳过、不得硬扛、不得伪造结果** |
| 6 | dev 的 hm 体系**不含设备工具链来源解析**（`hdc` 来自哪个 SDK / 是否在 PATH） | 按 `ai-team-dev-pt-hm-env` E6 探索口径定位；仍不明确 → `ask_followup_question` 让用户提供路径，**不得静默假定可用** |

> **缺口登记要求**：因上表缺口导致某项无法验证 → 记入报告「未覆盖项与风险」并写明原因，**禁止伪造通过**。

## 新增平台

在表格中新增一行即可。若某平台只有部分能力，对应列留空。

> **环境事实归属**：路径 / 工具链 / 版本 / 命令等**平台特有事实由该平台的「环境事实」skill 持有**，本领域 skill 引用而不复制；本文件只做路由，**不内联任何命令**。
