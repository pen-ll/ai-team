# 长篇叙事结构规范（structure-standards）

> **定位**：写作领域「结构顾问」的方法论产出。本文所有条目均为**可执行判据 / 表格 / 模板**，供 write 领域 SKILL.md 直接转写为检查项与产出物模板。
> **适用**：≥ 20 章或 ≥ 8 万字的长篇连载（含网文、系列小说、分卷长篇）。
> **不适用**：单章短篇、散文、非叙事文本。

## 使用方式（线性流程）

```
① 立项 → 建三份台账（结构检查清单 / 张力曲线表 / 伏笔台账）
② 逐章写 → 每章登记：所属幕·卷 + 章功能 + 峰值张力 + 章末钩子
③ 每卷末 → 卷复盘（本卷起承转合是否闭环）
④ 放行门禁 → 见「七、门禁」（任一门禁不通过即阻塞，不得继续推进）
```

## 一、结构检查清单（三幕 / 起承转合 落地）

### 1.1 三层嵌套模型

长篇在三个尺度上同时成立结构，**写作时必须逐层对齐**：

| 层 | 骨架 | 作用 |
|----|------|------|
| **全书层** | 三幕 | 整体力量走向（建置→对抗→解决） |
| **卷层（弧）** | 起承转合 | 每一卷是一次完整呼吸，有独立目标与收束 |
| **章层** | 场景-续景 | 单章必须有进入 / 变化 / 离开 |

> 判定原则：**任何一层不能只剩骨架而无验收信号**。三幕不落卷 = 空喊；卷不落章 = 卷末才发现没铺垫。

### 1.2 全书三幕：目标与验收信号

| 幕 | 章数占比（20-40 章） | 章数占比（100+ 章） | 幕目标 | 验收信号（可逐章比对） | 未达标症状 |
|----|----------------------|---------------------|--------|------------------------|-----------|
| **Act1 建置** | 15-20% | 10-15% | 建立主角、世界规则、核心冲突、主题承诺 | ① 主角目标已明确 ② 核心冲突已登场 ③ 读者能复述"这书讲什么" | 还在铺设定 / 无明确目标 |
| **Act2 对抗** | 55-60% | 60-70% | 冲突升级、中点反转、至暗时刻 | ① 中点（50%）有认知反转或局势逆转 ② 卷间赌注递增 ③ 至暗时刻（75% 附近）主角失去依仗 | 平面推进、无升级、主角全程被动 |
| **Act3 解决** | 20-25% | 15-25% | 高潮对决、收束主线、回收伏笔、余韵 | ① 高潮章张力 = 10 ② 核心悬念全部回收 ③ 结尾给出情绪余韵或新平衡 | 仓促收尾 / 伏笔烂尾 / 高潮无铺垫 |

### 1.3 卷层起承转合：每卷目标与验收信号

| 卷内拍 | 占比 | 本拍目标 | 验收信号 | 常见错误 |
|--------|------|----------|----------|----------|
| **起** | 15-25% | 建立本卷新目标 / 新场域 / 新关系 | 卷首 3 章内明确"本卷要解决什么" | 直接续上卷、无新目标 |
| **承** | 40-50% | 升级冲突、深化关系、埋设并推进伏笔 | 每 2-3 章至少一次明确推进（情节/关系/信息其一） | 原地打转、纯日常水字数 |
| **转** | 15-20% | 本卷高潮前的反转或重大危机 | 出现"局势逆转"事件，主角既定计划失败 | 转角过小、读者不意外 |
| **合** | 10-15% | 结算本卷冲突、回收本卷伏笔、抛下卷钩子 | 本卷主冲突解决 + ≥1 上卷遗留回收 + 结尾新钩子 | 高潮后拖尾、无新钩 |

> **单卷自洽门禁**：每卷必须能作为"一个可独立阅读的完整故事单元"，同时留一条线牵住下一卷。

### 1.4 章层：最小结构单元

每章必须同时满足：

| 项 | 判据 |
|----|------|
| **进入** | 章首 1-2 段交代时间/地点/在场人，读者不迷路 |
| **变化** | 本章结束时的状态 ≠ 章首（推进情节 / 关系 / 信息 / 主题 至少其一） |
| **离开** | 章末有钩子（悬念 / 期待 / 反转 至少其一） |
| **服务** | 本章可挂到某幕某卷的某个目标下（挂不上 = 冗余章） |

### 1.5 逐章比对表（模板见 §6.1）

登记字段：`章号 | 所属幕 | 所属卷 | 章功能 | 本章变化 | 峰值张力 | 章末钩子 | 幕目标对齐(是/否) | 通过`

## 二、张力曲线

### 2.1 定义

- **张力值**：记为**本章内最紧张时刻的峰值张力**（非平均值）——读者只记得峰值，平均值会掩盖真实节奏。
- **取值范围**：1-10 的整数。
- **标注时机**：每章完稿后即时标注，不得事后批量估算。

### 2.2 判定锚点（什么章该是几分）

| 值 | 档位 | 判定锚点（本章峰值满足任一即落入该档） | 读者感受 |
|----|------|----------------------------------------|----------|
| **1** | 静态 | 纯环境/心理描写，无目标、无阻碍 | 放松、可跳读 |
| **2** | 铺垫 | 日常互动或信息交代，人物处境无实质变化 | 温和、铺垫感 |
| **3** | 微扰 | 出现小麻烦/小情绪，无后果、可立即化解 | 轻微在意 |
| **4** | 起步冲突 | 欲望受阻，对立面出现，但主角尚有退路 | 产生期待 |
| **5** | 对抗升级 | 明确对手施压，代价浮现，退路收窄 | 专注 |
| **6** | 严重受挫 | 主角计划失败 / 失去依仗 / 重要关系破裂 | 紧张 |
| **7** | 危机 | 重大代价或不可逆损失迫近，主角被迫抉择 | 屏息 |
| **8** | 绝境 | 生死或核心价值悬于一线，翻盘概率低 | 焦灼 |
| **9** | 反转/重大失去 | 认知被颠覆 / 关键人物死亡或背叛 / 计划彻底瓦解 | 震动 |
| **10** | 全书高潮 | 核心冲突正面对决，主角押上全部赌注并做终局选择 | 顶峰 |

### 2.3 打分流程（先定基础档，再加减触发器）

```
第 1 步：按「冲突性质」定基础档
  无冲突/纯日常 → 2 ；意图受阻(小阻力) → 4
  明确对抗(有对手施压) → 6 ；不可逆危机(重大失去/生死) → 8
第 2 步：叠加「上调触发器」，每命中 +1
第 3 步：叠加「下调触发器」，每命中 −1
第 4 步：夹到 [1,10]，记录最终值
```

**上调触发器**（每项 +1）：

| # | 触发器 | 判据 |
|---|--------|------|
| U1 | 时间压力 | 本章出现倒计时/截止/即将发生的确定事件 |
| U2 | 不可逆性 | 本章后果无法撤回（死亡、成婚、契约、毁物） |
| U3 | 信息差最大化 | 一方掌握关键信息而另一方不知（误解/隐瞒/埋伏） |
| U4 | 核心价值受挑战 | 主角信念或最重要关系被正面攻击 |
| U5 | 前情债务到期 | 前文伏笔或旧冲突在本章被结算 |
| U6 | 章末悬置 | 章末钩子未闭合且威胁明确 |

**下调触发器**（每项 −1）：

| # | 触发器 | 判据 |
|---|--------|------|
| D1 | 停顿 | 穿插大段说明/回忆（> 本章 20% 篇幅） |
| D2 | 重复 | 场景或情绪与近 3 章高度雷同、无新增 |
| D3 | 离场 | 主视角离开主线，切至无关支线 |

### 2.4 张力曲线健康判据（数值化）

| # | 判据 | 阈值 | 违反后果 |
|---|------|------|----------|
| H1 | 无塌陷 | 不存在**连续 ≥5 章**峰值 ≤4 | 判定「中段塌陷」 |
| H2 | 有峰值 | 全书 ≥1 章达 9，**高潮章 = 10** | 无高潮感 |
| H3 | 每卷有局峰 | 每卷内 ≥1 章 ≥7 | 卷内平淡 |
| H4 | 波动适度 | 相邻章差值 ≤4（超过须为刻意转折并在台账注明） | 情绪断裂或读者疲劳 |
| H5 | 谷底不空 | 峰值 ≤3 的章占比 ≤30%，且不连续 >3 章 | 水字数 |
| H6 | 上升包络 | 幕内均值递增：Act3 均值 ≥ Act2 均值 ≥ Act1 均值 | 力量感递减 |

### 2.5 典型崩坏曲线

| 崩坏形态 | 曲线形状 | 数值特征 | 根因 | 修法 |
|----------|----------|----------|------|------|
| **中段塌陷**（middle sag） | 高 → 低平 → 高 | 25%-60% 区间**连续 ≤4** | 核心冲突未升级、主角被动 | 设置中点反转、给主角主动目标、压缩日常 |
| **早泄式峰值** | 陡起 → 长平 | Ch2-3 达 8+，其后 **>10 章 ≤5** | 开局过度承诺 | 早期大事件延后，或对后续持续升级 |
| **锯齿平庸**（flatline） | 全程 4-6 锯齿 | 无 ≥8 章，标准差 <1.5 | 无真正赌注、不敢伤害主角 | 提高代价与不可逆性，补中点与高潮 |
| **伪递增** | 单调缓升 | 相邻差 ≤1 且全程无谷 | 无节奏对比 | 插入呼吸章/低点，制造落差 |
| **悬崖高潮** | 末段垂直拉满 | Act3 前 ≤5，末 2 章突至 10 | 高潮无铺垫 | 前移铺垫，用伏笔台账补线 |

## 三、黄金三章

### 3.1 分章任务分解

| 章 | 必须完成的任务（缺一不可） | 验收信号 | 常见错误 | 失败判定 |
|----|---------------------------|----------|----------|----------|
| **第 1 章** | ① **钩子**：前 300 字内出现"异常 / 欲望 / 危机"之一<br>② **身份建立**：主角身份 + 当下处境 + 一个鲜明特质<br>③ **世界规则冰山**：透露核心设定但**展示而非说明**<br>④ **即时悬念**：章末抛出即时问题 | 读者能回答"主角是谁、想要什么、什么麻烦在靠近" | 大段设定说明 / 主角无欲望 / 钩子太弱 | 任一项不可复述 |
| **第 2 章** | ① **动机确认**：主角为何必须行动（why now，非"因为剧情"）<br>② **引入关键角色/对手或其代理**，展示关系张力<br>③ **首次冲突雏形**：外部压力显性化<br>④ **悬念闭环**：回答第 1 章表层钩子，同时开一个更大的钩 | 至少一个悬念在本章被**明确回答** | 仍在铺设定 / 无冲突 / 悬念不闭环 | 第 1 章钩子悬置未答 |
| **第 3 章** | ① **首次正面冲突**：主角**主动**做出选择或行动（非被动挨打）<br>② **能力/缺陷展示**：让读者知道主角凭什么、缺什么<br>③ **核心冲突与赌注确立**：真正的大问题登场<br>④ **主钩**：给出"必须继续读"的理由 | 读者能复述全书核心冲突，并有明确追读意愿 | 主角仍被动 / 核心冲突未登场 / 无追读钩 | 核心冲突未在第 3 章末登场 |

12 项逐项判定，**全部为"是"方可写第 4 章**（见 §7 门禁 G1）。

## 四、伏笔台账

### 4.1 字段设计

| 字段 | 必填 | 说明 |
|------|------|------|
| `FID` | 是 | 唯一编号，格式 `F-{NNN}` |
| `埋设章` | 是 | 伏笔首次出现的章号 |
| `埋设载体` | 是 | 物件 / 对白 / 细节 / 规则 / 人物 / 场景 |
| `内容摘要` | 是 | 一句话描述伏笔内容 |
| `服务对象` | 是 | 指向的剧情点 / 核心冲突 / 人物弧 |
| `计划回收章` | 是 | 计划兑现的章号（可为区间） |
| `类型` | 是 | 短期(本卷内) / 中期(1-2 卷) / 长期(全书) |
| `强度` | 是 | 明线（读者已知是线索）/ 暗线（读者初读不觉） |
| `状态` | 是 | 未回收 / 已回收 / 失效 / 需补埋 / 逾期 |
| `实际回收章` | 否 | 回收后填写 |
| `回收方式` | 否 | 揭晓 / 反转 / 呼应 |
| `关联伏笔` | 否 | 其他 FID（成组伏笔） |

### 4.2 容忍窗口

回收允许延期，但不得超过窗口：

| 类型 | 容忍窗口 |
|------|----------|
| 短期 | 计划回收章 **+3 章** |
| 中期 | 计划回收章 **+1 卷** |
| 长期 | **全书末**（Act3 内必须回收） |

### 4.3 回收判定规则

| 状态 | 判定条件（需同时满足） | 后续动作 |
|------|------------------------|----------|
| **已回收** | ① 在某章被明确揭示或兑现；② 读者可回溯到埋设点（形成呼应）；③ 实际回收章 ≤ 计划回收章 + 容忍窗口 | 登记实际回收章与方式 |
| **需补埋** | 距计划回收章 ≤3 章，但埋设强度不足以支撑回收（重读找不到依据） | 在回收前 1-3 章内补一次强化 |
| **逾期** | 已过计划回收章、未回收，但仍在容忍窗口内 | 本卷内必须回收或降级，不得继续拖延 |
| **失效** | 已过容忍窗口仍未回收，且剧情已不再依赖 | 二选一：**删除**（可从文本移除）或**降级**为氛围细节（台账标注不再回收） |
| **冲突消解** | 两条伏笔指向同一回收点且互相矛盾 | 合并为一条，或废弃其一 |

### 4.4 状态流转

```
新伏笔 → 登记（埋设章 + 计划回收章 + 类型）
   ↓ 每卷末核对
状态 = 未回收
   ├─ 计划回收章临近(≤3章) 且强度不足 → 需补埋 → 补埋后回归「未回收」
   ├─ 已过计划回收章 ≤ 容忍窗口        → 逾期   → 本卷内回收
   └─ 已过容忍窗口 且 剧情不再依赖      → 失效   → 删除 / 降级
回收发生 → 校验三条件 → 已回收
```

### 4.5 台账健康阈值

| 指标 | 阈值 | 含义 |
|------|------|------|
| (逾期 + 失效) / 总伏笔数 | ≤ 30% | 超过即伏笔烂尾（门禁 G5） |
| Act3 前的未回收长期伏笔 | ≤ 5 条 | 超过则收束压力过大，需提前回收或降级 |
| 单章新增伏笔 | ≤ 3 条 | 超过则信息过载 |

## 五、常见结构崩坏模式表

| # | 现象 | 根因 | 修法 | 检测信号（可量化） |
|---|------|------|------|--------------------|
| 1 | **中段塌陷** | 核心冲突未升级、主角被动 | 中点反转 + 主动目标 + 压缩日常 | 连续 ≥5 章峰值 ≤4 |
| 2 | **主线稀释** | 支线喧宾夺主 | 支线须服务主线或人物弧，否则删/并 | 支线篇幅占全卷 > 40% |
| 3 | **高潮无力** | 高潮张力低于前期峰、无铺垫 | 重新分配张力，补线至高潮 | 高潮章张力 < 前期峰值，或未达 10 |
| 4 | **伏笔烂尾** | 埋而不收、收了也不解释 | 按 §4 台账回收/降级 | (逾期+失效)/总数 > 30% |
| 5 | **人物降智** | 为推进剧情牺牲人设 | 决策须符合已建立人设与信息 | 关键决策违背已设人设且无理由 |
| 6 | **公式化疲劳** | 连续复用同一章型套路 | 交替章型（升级/关系/信息/反转） | 连续 ≥5 章采用相同章型结构 |
| 7 | **信息倾倒 / 谜语人** | 一次倒完设定 / 无故隐瞒 | 拆分投放；隐瞒须有角色动机 | 单章设定说明 > 20% 篇幅，或关键信息被无故扣留 |
| 8 | **目标漂移** | 主角目标无事件支撑地改变 | 目标变更须由剧情事件触发 | 主线目标在无触发事件下改变 |
| 9 | **视角混乱** | 单场景内跳 POV | 一场一 POV，切换须分隔 | 单场景内 POV 切换无分隔符 |
| 10 | **收尾仓促** | Act3 章数不足以承载回收量 | 提前收束支线、前移高潮 | Act3 占比 < 10% 且待回收伏笔过多 |
| 11 | **张力钝化** | 频繁假危机，读者脱敏 | 假危机占比受控，真危机有代价 | 假危机（虚惊一场）占危机事件 > 30% |
| 12 | **开局劝退** | 三章钩子/冲突/闭环缺失 | 按 §3 黄金三章重写 | 黄金三章体检任一项为"否" |

## 六、产出物模板（可直接复制）

### 6.1 结构检查清单（逐章 · 唯一主台账）

```markdown
| 章号 | 所属幕·卷 | 章功能 | 本章变化 | 峰值张力 | 章末钩子类型 | 幕目标对齐 | 通过 |
|------|-----------|--------|----------|----------|--------------|------------|------|
| 1 | Act1·卷1 | 建置 | 主角苏醒并发现异常 | 4 | 悬念 | 是 | ✅ |
```

**固定接口字段（供其他角色交叉校验；字段名与值域不得随意变更）**：

| 字段 | 值域 |
|------|------|
| `所属幕·卷` | `Act1`/`Act2`/`Act3` · 卷号，如 `Act2·卷3` |
| `章功能` | 建置 / 升级 / 关系 / 信息 / 反转 / 呼吸 / 结算 |
| `峰值张力` | 1-10 整数（锚点见 §2.2） |

## 七、门禁（可直接转写为 SKILL 检查项）

### [门禁] 硬约束

| # | 门禁 | 判据 | 违反处理 |
|---|------|------|----------|
| **G1** | 黄金三章 | §3.2 体检表 12 项全为"是" | 阻塞：不得写第 4 章，先重写三章 |
| **G2** | 无中段塌陷 | 不存在连续 ≥5 章峰值 ≤4 | 阻塞：须插入升级事件 |
| **G3** | 有高潮 | 全书 ≥1 章达 9，高潮章 = 10 | 阻塞：结构不通过 |
| **G4** | 卷自洽 | 每卷有局峰(≥7) 且卷末闭环 | 阻塞：该卷须重排 |
| **G5** | 伏笔健康 | (逾期+失效)/总数 ≤ 30% | 阻塞：先清台账再推进 |
| **G6** | 逐章登记 | 每章登记：所属幕·卷 + 章功能 + 峰值张力 + 章末钩子，缺项不通过 | 阻塞：补齐后放行 |

### 软建议（可弹性）

- 相邻章张力差值 ≤4；超过时须为刻意转折并在台账注明（默认执行；若为刻意节奏设计则放行并留痕）。
- 峰值 ≤3 的章占比 ≤30%（默认执行；过渡卷可放宽至 35%，须说明理由）。
- 单章新增伏笔 ≤3 条（默认执行；卷首章可放宽至 5 条）。
