## 0. 使用方式

- 本文件是**检查项集**，不是教程。每行 = 一条可执行判据，可直接转写为 SKILL.md 门禁或检查清单。
- 判据分三级，**级别决定处置动作**（详见第 3 节裁决清单）：

| 级别 | 含义 | 默认处置 |
|------|------|----------|
| P0 红线 | 命中即阻塞 | 必须回炉 |
| P1 黄线 | 命中记入修改建议 | 可放行（携带整改项） |
| P2 观察 | 不裁决，转数据驱动 | 留给读者反馈 |

- 判定统一口径：**默认按"连续/累计"计数判据；无数字阈值即按是否触发定性信号判定**。
- 除特别注明外，"章"指单章（2000-3000 字），"卷"指单卷（50-100 章）。

### 0.1 与 structure-standards.md 的边界（权威归属）

| 事项 | 权威文档 |
|------|----------|
| 三幕／起承转合配比、章层进入-变化-离开、黄金三章、张力曲线与峰值锚点、伏笔台账与回收窗口、结构崩坏模式、门禁 G1-G6 | `structure-standards.md`（结构侧，权威） |
| 文风／文字／校对／语句层、爽点／毒点、渠道与更新节奏、断章**位置**质量、编辑裁决 | 本文件（编辑侧，权威） |
| 人设、情节因果、名称一致性 | 本文件（无其他文档覆盖面，权威） |

**[门禁] 冲突优先级**：同一事项两文档阈值不一致时，**结构层判据以 `structure-standards.md` 为准**；编辑侧不另立更松或更严的结构阈值。本文 §1.1／§1.5 仅保留结构侧未覆盖的**审稿侧信号**，不重复定义结构判据。

## 1. 审稿七维判据表

### 1.1 结构

| 编号 | 判定信号（可直接扫描） | 触发阈值 | 级别 |
|------|------------------------|----------|------|
| S1 | 主线断链：主角未接近也未远离核心目标 | 连续 ≥2 章 | P0 |
| S2 | 支线失控：并行支线中任一条与主线无交集 | 单卷并行支线 >3 条且其中 ≥1 条连续 ≥5 章无交集 | P1 |
| S3 | 结构错位：高潮章内过场/日常段落占比 | >40% | P1 |

### 1.2 情节

| 编号 | 判定信号（可直接扫描） | 触发阈值 | 级别 |
|------|------------------------|----------|------|
| P1 | 冲突升级断档：冲突强度、参与方数量、失败代价三者均无提升 | 连续 ≥5 章（对齐 structure-standards G2） | P0 |
| P2 | 巧合推动：关键转折由巧合/天降外力解决，且主角此前无对应铺垫 | 单卷 ≥2 次 | P0 |
| P3 | 场景三要素缺失：主角"想要什么/阻碍是什么/失败代价"缺 ≥1 项 | 单场景命中即计 | P1 |
| P4 | 信息差失效：主角漏用其已掌握且读者已知的关键信息，制造假危机 | 单卷 ≥2 次 | P1 |

## 2. 长篇体裁基线

### 2.1 单章字数区间

| 题材/渠道 | 单章字数 | 说明 |
|-----------|----------|------|
| 男频付费（玄幻/仙侠/都市/系统） | 2000-4000 | 订阅平台；同卷内波动 ±20% 内 |
| 男频免费（番茄/七猫类） | 2000-3000 | 强钩子，章末必留悬念 |
| 女频付费（现言/古言/言情） | 2000-3000 | 情绪推进优先于设定铺陈 |
| 女频免费 | 1500-2500 | 短章高频、情绪点密集 |
| 下限校验 | 付费 <1200 / 免费 <1000 | 内容体量不足，判并章或补写 |
| 上限校验 | >5000 | 视为并章，判拆分重断章 |

### 2.2 更新节奏

| 判据 | 基线 | 级别 |
|------|------|------|
| 商业化最低线 | 日更 ≥1 章（≥2000 字） | P1 |
| 商业化标准线 | 日更 2 章（4000-6000 字/日） | P2（达标项） |
| 新书期（上架前 30 天） | 不得断更 | P0 |
| 断更 | 连续 >2 天 | P0（运营红线） |
| 上架前存稿 | ≥10 章 | P1 |
| 加更触发 | 推荐票/月票/打赏达标 +1 章/次 | P2 |

### 2.3 断章位置规则

> **边界**：章末**是否有钩子**属结构层，由 `structure-standards.md` G6 门禁；本节只定义钩子的**位置质量**与渠道要求。

| 判据 | 规则 | 级别 |
|------|------|------|
| 必须断在 | "信息即将揭露 / 冲突即将爆发 / 决定已做未执行"三类之一 | P1 |
| 禁止断在 | 场景收束、情绪平复、对话交代完毕处 | P1 |
| 章末最后一段 | 禁止为总结抒情段（100-200 字区间） | P1 |
| 关键付费章 | 上架章及高转化章须断在全书级强钩 | P1 |
| 连续校验 | 连续 ≥2 章断在收束/平复处（钩子质量分不及格） | P1 |

### 2.4 前 10 章留存关键动作

> **边界**：第 1-3 章以 `structure-standards.md` §3「黄金三章」为权威；本节覆盖**第 4-10 章延伸 + 渠道留存动作**。

| 章节 | 必须完成的动作 | 级别 |
|------|----------------|------|
| 第 4-5 章 | 确立主线目标；树立首个反派/对手 | P1 |
| 第 6-7 章 | 完成首个"冲突-升级-兑现"闭环（爽点模式定型） | P1 |
| 第 8-10 章 | 格局初展（更大势力/更大目标）；章末留追读钩 | P1 |
| 前 10 章禁止 | 大段世界观科普、主角长期受压制、无金手指展示、视角分散至配角 | P0 |

### 2.5 卷末节奏

> **边界**：卷内起承转合与卷末闭环由 `structure-standards.md` §1.3 / G4 判定；本节只补**渠道侧卷长与收益兑现基线**。

| 判据 | 规则 | 级别 |
|------|------|------|
| 卷长 | 付费 50-100 章 / 免费 30-60 章 | P2 |
| 卷末高潮段 | 最后 3-5 章：主要矛盾解决 + 主角明确收益（升级/地盘/身份/感情） | P0 |
| 卷末钩子 | 最后 1-2 章埋下卷钩（新敌人/新世界/新目标） | P1 |
| 禁止 | 矛盾未解即切卷；高潮后大段日常拖尾（>2 章） | P0 |

## 3. 主编裁决清单

> **边界**：A1／A2／A5／A8／A9 与 structure-standards §7 门禁 G1-G6 同源同判；两文件任一命中即回炉，阈值不一致时以结构侧门禁为准。

### 3.1 必须回炉重写（命中任一即打回）

| 编号 | 回炉条件 |
|------|----------|
| A1 | 前 3 章未出现核心冲突 / 金手指 / 关键身份异常 |
| A2 | 连续 ≥3 章无爽点（Y1），或连续 ≥5 章无冲突升级（P1 / G2） |
| A3 | 主角憋屈连续 ≥5 章未释放（D1 加重档） |
| A4 | 命中平台政策红线（D6） |
| A5 | 单卷支线 >3 且主线停滞（S2 加重档） |
| A6 | 关键转折靠巧合解决 ≥2 次/卷（P2）或因果断裂（P6） |
| A7 | 主角强行降智（D2）、代入资产清零（D5）、感情雷区（D4） |
| A8 | 主角行为漂移（C3）、名称不一致（W6） |
| A9 | 连续 ≥2 章断在收束/平复处（2.3 钩子质量） |
| A10 | 新书期断更或连续断更 >2 天（运营红线，2.2） |

### 3.2 可放行（黄线内，记入修改建议但不阻塞）

| 编号 | 可放行条件 |
|------|------------|
| B1 | 单章字数在区间外但 ±10% 以内 |
| B2 | 视角切换但有明确分隔符（空行/分节符） |
| B3 | 单次巧合推动（≤1 次/卷）且有前置暗示 |
| B4 | 配角口癖缺失但该配角累计戏份 <5 章 |
| B5 | 单段略超 150 字但无信息冗余 |
| B6 | 支线交叉主线 ≥5 章内一次但条数未超限 |
| B7 | 反派动机薄弱但本轮冲突即将收束（≤2 章内解决） |
| B8 | 章长波动超 ±40% 但为卷末/高潮特殊章（需标注） |

### 3.3 留给读者反馈决定（不预先裁决，数据驱动）

| 编号 | 待决事项 | 判定依据 |
|------|----------|----------|
| C-1 | 感情线主角人选 / CP 归属 | 评论区情绪、CP 相关章评量、追订波动 |
| C-2 | 配角是否死亡/退场 | 读者情绪反馈 vs 主线需要 |
| C-3 | 支线是否展开（对主线影响 <20%） | 该支线章节追读率 vs 本卷均值 |
| C-4 | 题材/风格微调（是否加入喜剧/异能元素） | 掉收率、章评关键词 |
| C-5 | 更新节奏微调 | 读者投票、打赏/催更数据 |
| C-6 | 设定/番外扩写 | 评论区需求密度 |

> 裁决数据门槛：追读率或章评反馈出现**显著偏离本卷均值**（建议阈值 ±15%）时，转为决策依据。

| 类型 | 触发信号 | 常用铺垫 |

## 5. 门禁转写约定（供 SKILL.md 直接引用）

| 转写类型 | 对应判据 | 建议写法 |
|----------|----------|----------|
| 硬门禁（阻塞出稿） | 本文件全部 P0 判据 + 3.1 回炉清单 + structure-standards G1-G6 | `[门禁]` 前置，命中即回退重写 |
| 软检查（随稿交付整改项） | 本文件全部 P1 判据 + 3.2 可放行项 | 输出整改建议列表，不阻塞 |
| 数据观察项 | 本文件全部 P2 判据 + 3.3 待决项 | 记入追踪表，转读者/数据裁决 |

- 审稿输出最小格式：`{判据编号} | 命中位置（章/段） | 级别 | 处置`。
- 任一 P0 命中 → 该章为**未通过**，禁止进入下一章/卷的放行流程。
- 结构层判据（S/P 系列中标注"对齐"者）命中时，**引用 structure-standards 对应门禁编号**，不重复描述修法。
