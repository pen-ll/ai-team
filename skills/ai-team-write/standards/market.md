## 触发与定位

本规范是「市场顾问」角色的工作流与产出模板：输入我方作品设定与资源，输出内容层竞品对标结论。

| 项 | 定义 |
|------|------|
| 角色职责 | 对标同题材/同类型作品，判定雷同风险，推导差异化定位；**只做内容层，不做商业变现、渠道、定价** |
| 输入 | 我方作品设定（题材/核心设定/人设/金手指/预期读者）+ 竞品素材（可公开获取的作品信息） |
| 产出 | `{artifact_dir}/market-report.md`（按本文第四节模板填写） |
| 不做 | 不评价竞品商业表现、不臆造竞品未公开设定、不复制竞品原文 |

**分析流程 SOP**（严格顺序执行，不可跳步）：

```
[1] 明确对标范围 → 先枚举同题材公开作品形成候选池并记录「对标范围记录」，再从中选 3-8 部
[2] 采集公开信息 → 仅取可核实来源，逐条标注可信度
[3] 填对标表 → 第二节字段逐列填写
[4] 雷同度判定 → 第三节五维度逐项定档 + 处置
[5] 差异化推导 → 第四节步骤，从「竞品优势 × 我方资源」生成定位
[6] 输出必须规避清单 + 纪律自检 → 第五节
```

> 样本量：默认对标 3-8 部（少于此无法归纳共性，多于此边际收益递减）；同题材公开作品不足时按实际数量执行并在产出中说明。

### 对标范围记录（必填，跨角色观测出口）

在枚举阶段（SOP 步骤 [1]）记录原始候选信息；这是**内容层可核实的观测事实**，供商业层引用。本规范只记录，不做商业价值判断（见 D4）。

| 字段 | 含义 | 取值/示例 |
|------|------|-----------|
| 题材边界 | 本任务对标的题材/读者层界定 | 如「都市异能 · 男频」 |
| 候选池规模 | 枚举到的同题材公开作品数（**截断前**） | 整数，如 21 |
| 是否截断 | 候选池是否被 3-8 部上限截断 | 是（池 > 8）/ 否（池 ≤ 8，已穷尽） |
| 检索范围 | 枚举依据的公开来源 | 平台/榜单/关键词等 |

> **交接约定**：`候选池规模 + 是否截断 + 题材边界` 三项组合才是可用信号——**只有「候选池规模」而不知「是否截断」不足以判断**（池=8 且截断 = 拥挤；池=3 未截断 = 稀疏）。商业层「竞争密度」可引用本记录，须注明来源为本文档「对标范围记录」；**密度高低的价值判断归商业层**，本规范不越界。

## 一、对标表字段设计

### 1.1 字段定义（必填列，顺序固定）

| 字段 | 含义 | 填写要求 |
|------|------|----------|
| 作品 | 竞品标识 | 作品名 +（可选）作者；同名作品须加区分标注 |
| 核心设定 | 该作最本质的世界观/题材内核一句话 | 一句话，≤40 字，不用剧情复述 |
| 开局钩子 | 开篇用什么抓住读者（悬念/冲突/金手指/反差） | 写「钩子类型 + 机制」，不抄原文 |
| 优势 | 该作相对同类明显更强的地方 | 客观归因，不写主观喜好 |
| 我方劣势 | 我方在该维度上的短板 | 逐条对应优势，不空泛 |
| 可借鉴 | 可迁移到我方的**方法/结构** | 只借结构与方法，不借具体设定与文本 |
| 必须规避 | 借鉴时绝不能踩的雷（红线） | 与「可借鉴」成对出现 |

### 1.2 附加列（必填，纪律要求）

| 字段 | 含义 | 取值 |
|------|------|------|
| 信息可信度 | 该行信息的事实可靠程度 | `已核实`（公开原文/官方设定集）/ `未核实`（传闻、二手转述、推测） |
| 来源 | 信息出处 | 书名/平台/章节等可定位标识 |

> **[门禁] 可信度缺省即未核实**：任何无法指向具体公开出处的信息，一律标 `未核实`，不得默认为事实。`未核实` 的条目不得作为「必须规避」红线的唯一依据。

## 二、雷同度判定维度

### 2.1 五个判定维度

| 维度 | 判定对象 | 判定要点 |
|------|----------|----------|
| 世界观规则 | 世界运行的根本法则（力量体系/社会规则/时空设定） | 规则**结构**是否一致，而非名词是否相同 |
| 核心设定 | 作品区别于同类的选题内核（题材母题 + 独特设定） | 母题是否重合 + 独特设定是否重合，两者都重合才算高雷同 |
| 人设组合 | 主要角色的**关系结构**与功能位（不是单个角色） | 关注「组合拓扑」（谁对谁、功能位如何配对），而非人名/外貌 |
| 关键剧情节点 | 推动主线转折的关键事件及其顺序 | 关注「节点序列 + 因果链」，而非场景描写 |
| 金手指类型 | 主角特权/外挂的类别与运作机制 | 关注「能力类型 + 获取方式 + 限制条件」三要素 |

### 2.2 判定档位与处置建议

| 档位 | 代号 | 判定标准 | 处置建议 |
|------|------|----------|----------|
| 相同 | S | 本质重合，替换名词后仍可对应 | **红线：必须重构该维度**，不得发布 |
| 高度相似 | A | 核心机制/结构一致，仅表述与细节不同 | 建议修改：至少改造一层（规则/组合/因果链任一层） |
| 同类不同实现 | B | 属同一类型，但具体实现、规则或限制条件明显不同 | 可保留：强化差异化表达，避免宣传话术撞车 |
| 无关联 | C | 无可比性 | 无需处理 |

### 2.3 判定矩阵模板

| 维度 | 竞品 | 档位（S/A/B/C） | 判定依据（指向具体重合点，非主观感受） | 处置动作 | 状态 |
|------|------|-----------------|----------------------------------------|----------|------|
| 世界观规则 | | | | | 待处理 |
| 核心设定 | | | | | 待处理 |
| 人设组合 | | | | | 待处理 |
| 关键剧情节点 | | | | | 待处理 |
| 金手指类型 | | | | | 待处理 |

> 每部竞品各出一张判定矩阵；多竞品可合并为一张，用「竞品」列区分。

### 2.4 综合判定规则

| 规则 | 说明 |
|------|------|
| **红线优先** | 五维度中**任一**为 `S（相同）` → 整体不通过，必须重构该维度后重判 |
| **瓶颈定级** | 无 S 时，综合档位取五维度中的**最差档位**（木桶原理），不取平均 |
| 档位分布记录 | 输出各维度档位分布，作为风险画像（集中高雷同的维度 = 风险集中点） |
| 重判触发 | 我方设定被修改后，受影响维度必须重新判定，不得沿用旧结论 |

## 三、差异化生成法

**核心公式**：`差异化定位 = 竞品优势（客观强项）× 我方资源（独有可用项）－ 雷同红线（必须规避项）`

### 步骤

| 步骤 | 动作 | 产出 |
|------|------|------|
| 1. 汇总优势 | 从对标表「优势」列去重，归纳为 3-5 条**共性优势**（多部竞品共有 = 赛道基准线） | 优势清单 |
| 2. 盘点资源 | 盘点我方独有可用项：原创设定 / 授权素材 / 考证能力 / 团队专长 / 稀缺素材 | 资源清单 |
| 3. 交叉匹配 | 逐对匹配「优势 × 资源」：我方资源能否**以不同方式**满足该优势？ | 差异化候选表 |
| 4. 红线反查 | 对每个候选执行第二节雷同度判定；命中 `S` → 淘汰，命中 `A` → 改造一层后再评估 | 过滤后候选 |
| 5. 收敛定位 | 从通过反查的候选中选 1 个主定位，写成一句话 + 3 条支撑点 | 差异化定位陈述 |
| 6. 输出规避表 | 汇总对标表「必须规避」列 + 反查淘汰原因，形成红线清单 | 必须规避清单 |

### 资源盘点表模板

| # | 我方资源 | 类型 | 是否独有/稀缺 | 与哪条优势相关 | 可用性 |
|---|----------|------|---------------|----------------|--------|
| 1 | | 原创设定/素材/能力 | 是/否 | | 可用/需开发/不可用 |

### 差异化候选表模板

| # | 竞品优势 | 我方资源 | 差异化方式（如何做到「同类不同实现」） | 红线反查结果 | 保留 |
|---|----------|----------|----------------------------------------|--------------|------|
| 1 | | | | C/B/A/S | 是/否 |

### 差异化定位陈述模板

```
主定位（一句话）：{面向谁 + 提供什么独特内容 + 与同类基准的差异点}
支撑点 1：{优势维度} → {我方资源} → {具体落地方式}
支撑点 2：…
支撑点 3：…
必须规避：{红线 1}、{红线 2}（来源：对标表 + 红线反查）
```

## 四、分析纪律（硬约束）

### [门禁] 不可违反项

| 编号 | 纪律 | 违规示例 | 正确做法 |
|------|------|----------|----------|
| D1 | **不妄断他人作品未公开设定** | 「该作主角后期一定是转世」（原著未写） | 只描述公开可见内容；未见即写「未核实」或不写 |
| D2 | **不复制他人具体文本** | 摘抄竞品原文段落作为对标内容 | 只用**概括性结构描述**，不复述原文句子/专有描写 |
| D3 | **事实缺失明确标注「未核实」** | 凭印象填「优势：节奏快」 | 无公开依据即标 `未核实`，并说明推断依据 |
| D4 | 内容层边界 | 分析渠道/定价/变现 | 只做内容层；商业维度交由其他角色 |
| D5 | 只借方法与结构 | 把竞品独有设定直接搬进我方 | 借「结构/机制/方法」，不借具体设定与文本 |

### 自检清单（产出前逐项确认）

- [ ] 对标作品 3-8 部，题材/读者层与对标范围说明一致
- [ ] 「对标范围记录」四项（题材边界/候选池规模/是否截断/检索范围）已填写
- [ ] 对标表 7 个必填列 + 可信度 + 来源均已填写
- [ ] 每条 `未核实` 信息未用于支撑 `S` 档判定或红线结论
- [ ] 五维度判定各有「具体重合点」依据，无主观感受式结论
- [ ] 综合档位按「红线优先 + 瓶颈定级」计算
- [ ] 差异化定位由「竞品优势 × 我方资源」推导，非凭空设想
- [ ] 未出现竞品原文摘抄、未臆断未公开设定
