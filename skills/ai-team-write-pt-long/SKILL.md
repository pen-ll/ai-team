# 写作形态特化 — 长篇小说（`long`）

## 触发

角色按注入的 `form_map` 路径 `read_file` 映射表，`form=long` 时加载。

## 覆盖范围

本 skill **覆盖或补充**写作角色通用流程中以下步骤；未列出的步骤仍按角色 skill 执行。

| 角色通用步骤 | 长篇特化行为 |
|--------------|-------------|
| 执笔 · 按批写作 | **按批推进**（默认 3-5 章/批）；**禁止逐章全员循环**（成本高、收益低） |
| 执笔 · 体裁基线 | 套用下方「连载体裁基线」（单章字数 / 更新节奏 / 断章规则） |
| 审稿人 · 结构门禁 | 套用下方 G1-G6 与卷级校验 |
| 执笔 + 审稿人 · S2 试写期 | 套用「黄金三章」专项（G1）与「前 10 章留存动作」 |
| 审稿人 · S4 收官期 | 套用「收官校验」（伏笔回收 + 全书一致性） |

## 一、按批推进（替代逐章循环）

```
每批 N 章（默认 3-5，由 PM 的 `范围` 参数指定）：
  1. 执笔读上下文包 → 连续写 N 章 → 每章产出 正文 + brief → 登记主台账
  2. 审稿人按批审查（读 brief 定位 + 按需读正文）→ 出分级与门禁判定
  3. 读者团（各口味实例）按批评分 → 出评分表与分歧项
  4. 主编按批裁决 → 放行 / 回炉
  5. 用户确认进入下一批
```

> **单章精修例外**：用户明确要求"只精修某一章"时，才对该章开全员（执笔 + 审稿人 + 读者团）。

## 二、连载体裁基线

细则见 `read_file("{skills_dir}/ai-team-write/standards/editor.md")` §2，此处只列必查项：

| 项 | 要求（区间与阈值一律以 `editor.md` §2 为准） |
|----|--------------------------------------------|
| 单章字数 | 按 §2.1 四档区间执行；下限 / 上限校验与处置（并章 / 补写）见 §2.1 |
| 更新节奏 | 断更红线与上架前存稿要求见 §2.2 |
| 断章规则 | 必须断在「信息将揭露 / 冲突将爆发 / 决定已做未执行」；**禁止**断在收束与平复处（详见 §2.3） |
| 卷末节奏 | 卷末高潮段章数、留钩子与切卷衔接要求见 §2.5 |

## 三、结构门禁（G1-G6）

判据与阈值以 `read_file("{skills_dir}/ai-team-write/standards/structure.md")` **§七** 为准——下表只列门禁编号，**不复制通过条件**：

| 门禁 | 通过条件出处 |
|------|-------------|
| G1 黄金三章 | `structure.md` §七（体检表 §3.2） |
| G2 张力健康 | `structure.md` §七 |
| G3 有高潮 | `structure.md` §七 |
| G4 卷自洽 | `structure.md` §七 |
| G5 伏笔健康 | `structure.md` §七 |
| G6 逐章登记 | `structure.md` §七（台账 §6.1） |

> **阈值冲突时以结构侧为准**（编辑侧判据不另立结构阈值）。
> **张力（1-10）与商业侧情绪强度（1-5）尺度不同，禁止换算与取均值。**

## 四、S2 试写期专项（黄金三章 + 前 10 章）

黄金三章逐章**必做动作**与体检项见 `structure.md` §3.1 / §3.2；**前 10 章**分段留存动作与「前 10 章禁止项」见 `editor.md` §2.4。本 skill 不复制清单——执行时**逐条按原文核对**并给出「过 / 不过 + 证据」。

> **S2 是止损点**：黄金三章体检 + 读者评分 + 审稿结论三者综合，由主编给出「是否继续写」的建议，用户决策。

## 五、S4 收官校验

| 校验 | 内容 |
|------|------|
| 伏笔回收 | 台账中「逾期 / 失效」项逐条核对；未回收项须补齐或明示销案 |
| 全书一致性 | 人名 / 时间线 / 能力设定 / 关键道具 / 视角人称跨卷比对 |
| 结构闭环 | 三幕验收信号逐条核对；高潮章张力是否达 10 |
| 节奏曲线 | 全书张力曲线无中段塌陷（形状判据见 structure.md §2.5） |

```yaml
form: long
batch_size_default: 4          # 3-5 章，由 PM 的 `范围` 参数覆盖

standards_structure: "{skills_dir}/ai-team-write/standards/structure.md"
standards_editor: "{skills_dir}/ai-team-write/standards/editor.md"
```
